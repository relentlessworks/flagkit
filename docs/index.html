Quick Start

make build
./flagkit
# → flagkit starting on :7707

# Auth
curl -d 'email=me@example.com' localhost:7707/auth/request
curl -d 'email=me@example.com&code=123456' localhost:7707/auth/verify

# Create a flag
curl -H 'Authorization: Bearer fk_xxx' \
     -d 'name=new_ui&type=boolean&enabled=true' \
     localhost:7707/flags

# Evaluate
curl -H 'Authorization: Bearer fk_xxx' \
     -d 'context=user123' \
     localhost:7707/flags/flag_k7m2q/evaluate

Principles

Agent IS the Interface

No UI, no SDK. The AI agent is the user. The API is the product.

Plain Text by Default

One labeled, grepable line per record. Token-cheap, survives context truncation.

Instructive Errors

Every 4xx includes a hint telling the agent what to do next.

Self-Documenting

GET /help returns a one-page operating manual the agent loads at runtime.

Simple Auth

OTP via email → long-lived bearer token. No complex OAuth.

Single Binary

Go + JSON file storage. Zero external dependencies. Deploys as one file.

Flag Types

Boolean

Simple on/off flag. Evaluate returns enabled=true/false.

Percentage

Percentage rollout (0-100%). Uses context key for consistent bucketing — same user always gets the same result.

Variant

A/B testing with multiple variants. Context key determines which variant is selected.
